01 · Problem & ownership

Why a plain LLM call is not enough

High-stakes case files are long, multi-document, and must be complete, consistent, and source-traced. A single prompt cannot enforce required-document rules, cross-file conflicts, or auditable citations — the system combines structured processing, rules, retrieval, and LLMs.

Problem

Reviewers must check identity, procedure, facts/evidence, and assets across OCR’d PDFs and transcripts — then draft notes with evidence attached.

What I owned

Built an AI document-analysis pipeline for large, sensitive case files in a fully offline environment — structured text processing, rule-based checks, retrieval, and LLMs. Designed and evaluated hybrid LLM + regex extraction and prompt workflows for multi-stage extraction; ran iterative error analysis to improve accuracy, consistency, and reliability.

Why not only LLM

Deterministic gates first (required docs, authority ranking); LLM for extraction and semantic conflict filtering; every claim keeps file + page + snippet for human audit.

04 · Evaluation & limitations

How we check quality — and what still needs humans

Quality is checked through structured gates, conflict surfacing, and reviewer edits — with clear limits on what automation can claim.

How we validate

  • Schema-validated structured outputs (retry on bad JSON)
  • Required-document completeness before “pass”
  • Conflict panels with source locations for reviewer confirmation
  • Graph cleanup: drop isolated nodes; relations only between known entities

Conflicts & provenance

  • Oral vs oral and oral vs document mismatches are surfaced, not silently merged
  • Every finding keeps file / page / snippet for click-through audit
  • Document-over-statement ranking is rule-based, then LLM filters noise

Still human-reviewed

  • Editable section summary before export
  • Ambiguous entity resolution and missing-file decisions
  • Final legal / compliance wording of draft notes

Limitations

  • OCR / scan quality still bounds upstream recall
  • LLM extraction can miss rare edge cases — gates + edit path are required
  • GraphRAG helps multi-hop questions; not a substitute for primary evidence checks
  • Deployed in access-controlled environments (auth, ACL, TLS)
